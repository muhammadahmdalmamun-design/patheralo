# পথের আলো

প্লে স্টোর ডেভেলপার একাউন্ট খোলার ধাপে ধাপে সহজ বাংলা সঙ্গী। ইন্টারনেট ছাড়াও চলে।

## ফোনে নামানোর নিয়ম
1. GitHub-এ নতুন repository খুলুন, নাম: `pather-alo` (Public)।
2. Add file → Upload files দিয়ে এই ৬টি ফাইল দিন: index.html, manifest.json, sw.js, icon-192.png, icon-512.png, README.md → Commit।
3. Settings → Pages → Branch: main, Folder: /(root) → Save।
4. ১–২ মিনিট পর লিংক পাবেন: https://আপনার-ইউজারনেম.github.io/pather-alo/
5. ফোনের Chrome-এ লিংক খুলুন → ⋮ মেনু → "Install app" বা "Add to Home screen"।
